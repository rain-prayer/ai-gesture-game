# 皮肤贴图

游戏启动时会尝试加载 `assets/<皮肤名>.png` 作为角色贴图；找不到就回退到代码绘制的几何角色。

内置皮肤与文件名对应关系：

| 皮肤 key | 名称 | 是否自带贴图 |
|----------|------|--------------|
| `green` | 经典绿 | ✅ |
| `neon`  | 烈焰喵 | ✅ |
| `ice`   | 冰晶龟 | ✅ |
| `gold`  | 黄金兔 | ✅ |
| `neo`   | 霓虹喵 | ✅ |

## 自定义贴图

1. 准备一张**背景透明**的 PNG（建议约 52×58 像素，角色脚底对齐图片底部）。
2. 命名为内置皮肤的 key（例如 `assets/ice.png` 会覆盖冰晶龟的贴图）。
3. 重新启动游戏即可生效；商城预览与局内角色会同步使用新贴图。

> 请只使用你有权使用的图片。仓库本身不附带任何第三方版权素材。
